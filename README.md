**Prerequisites:** 

1. Clone the repository using the project's Git URL 
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env.local` file and set the right environment variables

```
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_backend_url

e.g.
VITE_BASE44_APP_ID=cbef744a8545c389ef439ea6
VITE_BASE44_APP_BASE_URL=https://my-to-do-list-81bfaad7.base44.app
```

Run the app (frontend + local API): `npm run dev`

- **Frontend:** http://localhost:5173
- **API:** http://localhost:3001
- **Demo login:** `demo@garden.local` / `demo1234` (optional — guest mode works without login)

### Local backend

This repo includes a full Express API in `server/` with JSON storage:

- Auth: register, login, me
- Entities: Product, Order, UserGarden, QuizResult, User
- Garden sync, quiz results, recommendations, admin stats

API routes are proxied from Vite (`/api` → `http://localhost:3001`).
